# API設計

本システムでは、書籍情報を取得・操作するためのREST APIを提供します。

- レスポンスは **JSON形式** で返却します。
- レスポンスの整形には **API Resource** を使用します。
- 書き込み系API（POST / PUT / DELETE）は **Laravel Sanctum** によるBearerトークン認証を採用しています。
- 書籍の更新・削除は **BookPolicy** により、登録者本人のみ実行できます。

---

## エンドポイント一覧

| HTTPメソッド | URI | 説明 | 認証 |
|--------------|-----|------|------|
| GET | `/api/v1/books` | 書籍一覧を取得 | 不要 |
| GET | `/api/v1/books/{book}` | 書籍詳細を取得 | 不要 |
| POST | `/api/v1/books` | 書籍を登録 | Sanctum |
| PUT | `/api/v1/books/{book}` | 書籍を更新 | Sanctum + BookPolicy |
| DELETE | `/api/v1/books/{book}` | 書籍を削除 | Sanctum + BookPolicy |

---

## 書籍一覧取得 API

### エンドポイント

```http
GET /api/v1/books
```

### 概要

書籍一覧を取得します。

### 仕様

- キーワード検索に対応
- ジャンルによる絞り込みに対応
- ページネーションに対応
- ソートに対応
- 各書籍に以下の情報を含める
  - ジャンル一覧
  - 平均評価
  - レビュー件数

---

## 書籍詳細取得 API

### エンドポイント

```http
GET /api/v1/books/{book}
```

### 概要

指定した書籍の詳細情報を取得します。

### 仕様

レスポンスには以下を含めます。

- 書籍情報
- ジャンル一覧
- レビュー一覧
  - 投稿者名
  - 評価
  - コメント
  - 投稿日時

存在しないIDが指定された場合は適切なエラーレスポンスを返します。

---

## 書籍登録 API

### エンドポイント

```http
POST /api/v1/books
```

### 概要

新しい書籍を登録します。

### 仕様

- バリデーションエラー時は日本語のエラーメッセージを返却
- 登録成功時は適切なHTTPステータスコード（201 Created）を返却

---

## 書籍更新 API

### エンドポイント

```http
PUT /api/v1/books/{book}
```

### 概要

指定した書籍を更新します。

### 仕様

- 登録者本人のみ更新可能
- バリデーションは登録APIと同等
- ISBNの一意性チェックでは自分自身を除外
- 存在しないIDの場合は適切なエラーレスポンスを返却

---

## 書籍削除 API

### エンドポイント

```http
DELETE /api/v1/books/{book}
```

### 概要

指定した書籍を削除します。

### 仕様

- 登録者本人のみ削除可能
- 関連データ（レビュー・お気に入り・ジャンル紐付け）も適切に処理する
- 削除成功時は適切なHTTPステータスコード（204 No Content）を返却

---

## 認証

書き込み系APIでは **Laravel Sanctum** を利用したBearerトークン認証を採用しています。

### 認証方式

```
Authorization: Bearer {token}
```

### 認可

- POST：認証済みユーザーのみ実行可能
- PUT：認証済みかつ書籍登録者本人のみ実行可能
- DELETE：認証済みかつ書籍登録者本人のみ実行可能

未認証または認可エラー時は、適切なHTTPステータスコードを返却します。
