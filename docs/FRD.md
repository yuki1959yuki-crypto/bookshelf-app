# 機能要件

## 認証

| 画面名 | 操作 | URL / メソッド | 完了条件 |
|--------|------|----------------|----------|
| 会員登録画面 | ページを表示する | GET /register | 名前・メールアドレス・パスワード入力フォームが表示される |
| 会員登録画面 | 「登録」ボタンを押す | POST /register | ユーザーが登録される |
| ログイン画面 | ページを表示する | GET /login | ログインフォームが表示される |
| ログイン画面 | 「ログイン」ボタンを押す | POST /login | ログインが完了する |
| ログアウト | 「ログアウト」ボタンを押す | POST /logout | セッションが破棄されログイン画面へ遷移する |

## 書籍管理

| 画面名 | 操作 | URL / メソッド | 完了条件 |
|--------|------|----------------|----------|
| 書籍一覧画面 | ページを表示する | GET /books | 書籍一覧を表示する |
| 書籍一覧画面 | キーワード検索 | GET /books?keyword=xxx | 条件に一致する書籍を表示する |
| 書籍一覧画面 | ジャンル検索 | GET /books?genre=xxx | 条件に一致する書籍を表示する |
| 書籍一覧画面 | 並び替え | GET /books?sort=xxx | 指定順に表示する |
| 書籍登録画面 | ISBN検索 | GET /books/isbn/{isbn} | Google Books APIから書籍情報を取得しフォームへ反映する |
| 書籍登録画面 | 登録 | POST /books | 書籍を登録する |
| 書籍編集画面 | 更新 | PUT /books/{book} | 書籍情報を更新する |
| 書籍詳細画面 | 削除 | DELETE /books/{book} | 書籍を削除する |

## レビュー

| 画面名 | 操作 | URL / メソッド | 完了条件 |
|--------|------|----------------|----------|
| 書籍詳細画面 | 評価を選択し、レビューを入力して「投稿する」ボタンを押す | `POST /books/{book}/reviews` | バリデーション通過時→レビューが登録される<br>失敗時→バリデーションエラーが表示される |
| 書籍詳細画面 | レビューの「いいね」ボタンを押す | `POST /reviews/{review}/like` | レビューに「いいね」が登録される |
| 書籍詳細画面 | 自分のレビューの「編集」ボタンを押す | `GET /reviews/{review}/edit` | 認証＋投稿者本人→レビュー編集画面へ遷移する<br>認可が必要 |
| レビュー編集画面 | ページを表示する | `GET /reviews/{review}/edit` | 認証＋投稿者本人→既存の評価・レビュー内容が初期値として表示された編集フォームが表示される<br>認可が必要 |
| レビュー編集画面 | 内容を変更して「更新」ボタンを押す | `PUT /reviews/{review}` | 認証＋投稿者本人＋バリデーション通過→レビューが更新される<br>認可が必要 |
| 書籍詳細画面 | 自分のレビューの「削除」ボタンを押す | `DELETE /reviews/{review}` | 認証＋投稿者本人→レビューが削除される<br>関連する「いいね」も適切に削除される<br>認可が必要 |

## ジャンル管理

| 画面名 | 操作 | URL / メソッド | 完了条件 |
|--------|------|----------------|----------|
| ジャンル一覧画面 | ページを表示する | `GET /genres` | 認証時→各ジャンルに紐づく書籍数付きでジャンル一覧が表示される<br>未認証時→`/login`へリダイレクトされる |
| ジャンル一覧画面 | ジャンル名を押す | `GET /genres/{genre}` | ジャンル詳細画面へ遷移する |
| ジャンル一覧画面 | 「ジャンルを登録」ボタンを押す | `GET /genres/create` | ジャンル登録画面へ遷移する |
| ジャンル一覧画面 | 各ジャンルの「編集」ボタンを押す | `GET /genres/{genre}/edit` | ジャンル編集画面へ遷移する |
| ジャンル一覧画面 | 各ジャンルの「削除」ボタンを押す | `DELETE /genres/{genre}` | 書籍との紐付けがない場合はジャンルが削除される<br>書籍との紐付けがある場合は削除できない |
| ジャンル詳細画面 | ページを表示する | `GET /genres/{genre}` | 認証時→ジャンル名と紐づく書籍が10件/ページでページネーション表示される<br>未認証時→`/login`へリダイレクトされる |
| ジャンル登録画面 | ページを表示する | `GET /genres/create` | 認証時→ジャンル名入力フォームが表示される<br>未認証時→`/login`へリダイレクトされる |
| ジャンル登録画面 | ジャンル名を入力して「登録」ボタンを押す | `POST /genres` | バリデーション通過時→ジャンルが登録される<br>失敗時→バリデーションエラーが表示される |
| ジャンル編集画面 | ページを表示する | `GET /genres/{genre}/edit` | 認証時→現在のジャンル名が初期値として表示された編集フォームが表示される<br>未認証時→`/login`へリダイレクトされる |
| ジャンル編集画面 | ジャンル名を変更して「更新」ボタンを押す | `PUT /genres/{genre}` | バリデーション通過時→ジャンル名が更新される<br>失敗時→バリデーションエラーが表示される |

## 読書計画

| 画面名 | 操作 | URL / メソッド | 完了条件 |
|--------|------|----------------|----------|
| 読書計画一覧画面 | ページを表示する | `GET /reading-plans` | 認証時→ログインユーザーの読書計画一覧が表示され、状態による絞り込みおよび各種操作ボタンが表示される<br>未認証時→`/login`へリダイレクトされる |
| 読書計画一覧画面 | 状態を選択して絞り込む | `GET /reading-plans?status=xxx` | 選択した状態の読書計画のみが表示される |
| 読書計画一覧画面 | 「新規計画作成」ボタンを押す | `GET /reading-plans/create` | 読書計画作成画面へ遷移する |
| 読書計画一覧画面 | 「編集」ボタンを押す | `GET /reading-plans/{plan}/edit` | 認証＋所有者→読書計画編集画面へ遷移する<br>認可が必要 |
| 読書計画一覧画面 | 「読了する」ボタンを押す | `POST /reading-plans/{plan}/complete` | 認証＋所有者→読書計画のステータスが「読了」に更新される<br>認可が必要 |
| 読書計画一覧画面 | 「削除」ボタンを押す | `DELETE /reading-plans/{plan}` | 認証＋所有者→読書計画が削除される<br>認可が必要 |
| 読書計画作成画面 | ページを表示する | `GET /reading-plans/create` | 認証時→書籍選択プルダウンと読了予定日入力フォームが表示される<br>未認証時→`/login`へリダイレクトされる |
| 読書計画作成画面 | 書籍と読了予定日を入力して「登録」ボタンを押す | `POST /reading-plans` | バリデーション通過時→読書計画が登録される<br>失敗時→バリデーションエラーが表示される |
| 読書計画編集画面 | ページを表示する | `GET /reading-plans/{plan}/edit` | 認証＋所有者→既存の読了予定日が初期値として表示された編集フォームが表示される<br>認可が必要 |
| 読書計画編集画面 | 読了予定日を変更して「更新」ボタンを押す | `PUT /reading-plans/{plan}` | 認証＋所有者＋バリデーション通過→読書計画が更新される<br>認可が必要 |

### 日次バッチ処理

| 処理 | 実行方法 | 完了条件 |
|------|----------|----------|
| 読書計画のステータス更新・通知送信 | Laravel Scheduler | 毎日定刻に実行され、読了予定日を過ぎた読書計画のステータスを自動更新する。また、条件を満たす読書計画に対してリマインダー通知を送信する。 |

## 公開API

| 機能 | URL / メソッド | 完了条件 |
|------|----------------|----------|
| 書籍一覧を取得する | `GET /api/v1/books` | JSON形式で書籍一覧を返す。検索・絞り込み・ページネーションに対応し、各書籍にジャンル情報・平均評価・レビュー件数を含む |
| 書籍詳細を取得する | `GET /api/v1/books/{book}` | JSON形式で書籍詳細（ジャンル・レビューを含む）を返す。存在しないIDの場合は適切なエラーレスポンスを返す |
| 書籍を新規登録する | `POST /api/v1/books` | Sanctum認証済みユーザーのみ実行可能。バリデーション通過時は書籍を登録し、失敗時は適切なエラーレスポンスを返す |
| 書籍を更新する | `PUT /api/v1/books/{book}` | Sanctum認証済みかつ書籍所有者のみ実行可能。バリデーション通過時は書籍を更新し、存在しないIDや認可エラー時は適切なエラーレスポンスを返す |
| 書籍を削除する | `DELETE /api/v1/books/{book}` | Sanctum認証済みかつ書籍所有者のみ実行可能。書籍および関連データを適切に削除し、存在しないIDや認可エラー時は適切なエラーレスポンスを返す |
