# 機能要件一覧

## 1. 画面・機能仕様一覧

| 画面名 / 機能名 | 操作・アクション | URL / メソッド | 完了条件・詳細仕様 |
| :--- | :--- | :--- | :--- |
| **会員登録画面** | ページを表示する | GET /register | 名前・メール・パスワード・パスワード確認の入力フォームが表示される |
| | 「登録」ボタンを押す | POST /register | バリデーション通過時→ユーザーが作成される。<br>失敗時→エラーメッセージ表示。<br>認証にはLaravel Fortifyを使用。 |
| | 「アカウントをお持ちの方」ボタンを押す | GET /login | ログイン画面に遷移する |
| **ログイン画面** | ページを表示する | GET /login | メール・パスワードの入力フォームが表示される |
| | 「ログイン」ボタンを押す | POST /login | バリデーション通過時→ログインが完了する。<br>失敗時→エラーメッセージ表示。 |
| | 「アカウントをお持ちでない方」ボタンを押す | GET /register | 会員登録画面に遷移する |
| | 既にログイン済みでアクセスする | GET /login または /register | 書籍一覧（/）にリダイレクトされる |
| **書籍一覧画面（トップ）** | ページを表示する | GET / または GET /books | 書籍一覧が10件/ページでページネーション表示され、各書籍にジャンルが表示される。<br>ゲストもアクセス可能。 |
| | 書籍タイトルを押す | GET /books/{book} | 書籍詳細画面に遷移する |
| | 「書籍を登録」ボタンを押す | GET /books/create | 認証時→書籍登録画面に遷移する |
| **書籍詳細画面** | ページを表示する | GET /books/{book} | 書籍タイトル・著者・ISBN・出版日・説明・画像・ジャンル・レビュー一覧・いいね数が表示される。<br>ゲストもアクセス可能。 |
| | 「お気に入り」ボタンを押す | POST /books/{book}/favorites | 認証時→お気に入りトグル（追加/解除）される |
| | レビュー投稿（星選択＋コメント） | POST /books/{book}/reviews | 認証時→バリデーション通過後にレビューが保存される |
| | レビューの「いいね」ボタンを押す | POST /reviews/{review}/like | 認証時→いいねトグル（追加/解除）される |
| | 自分のレビューの「編集」ボタンを押す | GET /reviews/{review}/edit | 認証＋投稿者本人→レビュー編集画面に遷移（認可が必要） |
| | 自分のレビューの「削除」ボタンを押す | DELETE /reviews/{review} | 認証＋投稿者本人→レビューが削除される（関連いいねも適切に処理、認可が必要） |
| | 自分が登録した書籍の「編集」ボタンを押す | GET /books/{book}/edit | 認証＋作成者本人→書籍編集画面に遷移（認可が必要） |
| | 自分が登録した書籍の「削除」ボタンを押す | DELETE /books/{book} | 認証＋作成者本人→書籍が削除される（関連データも適切に処理、認可が必要） |
| **書籍登録画面** | ページを表示する | GET /books/create | 認証時→タイトル・著者・ISBN・出版日・説明・画像URLの入力欄と全ジャンル一覧のチェックボックス（複数選択可）が表示される。（応用時は「ISBN書籍情報自動入力フォーム」も含む） |
| | 全項目を入力して「登録」ボタンを押す | POST /books | バリデーション通過時→書籍が登録され、ジャンル紐付けが作成される。<br>失敗時→バリデーションエラーが表示される。 |
| **書籍編集画面** | ページを表示する | GET /books/{book}/edit | 認証＋作成者本人→既存データが初期値として表示された編集フォームが表示される（認可が必要） |
| | 内容を変更して「更新」ボタンを押す | PUT /books/{book} | 認証＋作成者本人＋バリデーション通過→書籍とジャンル紐付けが更新される（認可が必要） |
| **レビュー編集画面** | ページを表示する | GET /reviews/{review}/edit | 認証＋投稿者本人→既存のrating/commentが初期値として表示された編集フォームが表示される（認可が必要） |
| | 内容を変更して「更新」ボタンを押す | PUT /reviews/{review} | 認証＋投稿者本人＋バリデーション通過→レビューが更新される（認可が必要） |
| **お気に入り一覧画面** | ページを表示する | GET /favorites | 認証時→ログインユーザーのお気に入り書籍が10件/ページでページネーション表示される。<br>未認証時→ /login にリダイレクト。 |
| | 書籍タイトルを押す | GET /books/{book} | 書籍詳細画面に遷移する |
| **ジャンル一覧画面** | ページを表示する | GET /genres | 認証時→各ジャンルに紐づく書籍数付きでジャンル一覧が表示される |
| | ジャンル名を押す | GET /genres/{genre} | ジャンル詳細画面に遷移する |
| | 「ジャンルを登録」ボタンを押す | GET /genres/create | ジャンル登録画面に遷移する |
| | 各ジャンルの「編集」ボタンを押す | GET /genres/{genre}/edit | ジャンル編集画面に遷移する |
| | 各ジャンルの「削除」ボタンを押す | DELETE /genres/{genre} | 書籍紐付きの有無に応じて適切に処理される（紐付きがある場合は削除を制限） |
| **ジャンル詳細画面** | ページを表示する | GET /genres/{genre} | 認証時→ジャンル名と紐づく書籍がページネーション（10件/ページ）で表示される |
| **ジャンル登録画面** | ページを表示する | GET /genres/create | 認証時→ジャンル名入力フォームが表示される |
| | ジャンル名を入力して「登録」ボタンを押す | POST /genres | バリデーション通過時→ジャンルが登録される。<br>失敗時→バリデーションエラーが表示される。 |
| **ジャンル編集画面** | ページを表示する | GET /genres/{genre}/edit | 認証時→現在のジャンル名が初期値として表示された編集フォームが表示される |
| | ジャンル名を変更して「更新」ボタンを押す | PUT /genres/{genre} | バリデーション通過時→ジャンル名が更新される。<br>失敗時→バリデーションエラーが表示される。 |
| **ランキング画面** | ページを表示する | GET /ranking | レビュー平均評価のTOP10書籍が降順で表示される。<br>レビューがない書籍は表示されない。<br>ゲストもアクセス可能。 |
| **★ マイ読書レポート画面** | ページを表示する | GET /reports | 認証時→以下の4種の統計情報が表示される：<br>1. 基本サマリー（総レビュー数、読了冊数、平均評価点）<br>2. 評価分布（1〜5星ごとの件数を横バー表示）<br>3. 高評価書籍TOP5（4星以上、書籍詳細リンク付き）<br>4. ジャンル別評価傾向TOP5（平均評価と件数、ジャンル詳細リンク付き） |
| **ログアウト** | ヘッダーの「ログアウト」ボタンを押す | POST /logout | セッションが破棄されログイン画面にリダイレクトされる |
| **★ 読書計画一覧画面** | ページを表示する | GET /reading-plans | 認証時→ログインユーザーの読書計画を一覧表示し、状態による絞り込みができる。各計画に各種操作ボタンを表示。 |
| | 状態の絞り込みを変更する | GET /reading-plans?status=xxx | 選択した状態の計画のみ表示される |
| | 「読了する」ボタンを押す | POST /reading-plans/{plan}/complete | 認証＋所有者→計画のステータスが更新される（認可が必要） |
| | 「編集」ボタンを押す | GET /reading-plans/{plan}/edit | 認証＋所有者→読書計画編集画面に遷移（認可が必要） |
| | 「削除」ボタンを押す | DELETE /reading-plans/{plan} | 認証＋所有者→計画が削除される（認可が必要） |
| | 「新規計画作成」ボタンを押す | GET /reading-plans/create | 認証時→読書計画作成画面に遷移 |
| **★ 読書計画作成画面** | ページを表示する | GET /reading-plans/create | 認証時→書籍プルダウンと期日入力フォームが表示される。<br>未認証時→ /login にリダイレクト。 |
| | 書籍と期日を入力して「登録」ボタンを押す | POST /reading-plans | バリデーション通過時→計画が登録される。<br>失敗時→バリデーションエラーが表示される。 |
| **★ 読書計画編集画面** | ページを表示する | GET /reading-plans/{plan}/edit | 認証＋所有者→既存の期日が初期値として表示された編集フォームが表示される（認可が必要） |
| | 期日を変更して「更新」ボタンを押す | PUT /reading-plans/{plan} | 認証＋所有者＋バリデーション通過→計画情報が更新される（認可が必要） |
| **★ 通知一覧画面** | ヘッダーベルアイコンをクリック | GET /notifications | 認証時→ログインユーザーの通知一覧を表示。各通知に既読化操作を備える。 |
| | 「既読にする」ボタンを押す | POST /notifications/{id}/read | 認証＋所有者→当該通知が既読化される |
| **★ 日次バッチ処理** | 定刻実行 | Schedule 経由 | 毎日定刻に Schedule で実行される。<br>期日を経過した計画のステータスを自動変更し、一定条件を満たす計画にリマインダー通知を発火する。 |

## 2. 公開API・認証API要件

| エンドポイント名 | メソッド & URL | 仕様・条件 |
| :--- | :--- | :--- |
| **書籍一覧取得** | GET /api/v1/books | JSON形式で書籍一覧が返される（検索・絞り込み・ページネーション対応）。各書籍にジャンル情報・平均評価・レビュー件数を含める。 |
| **書籍詳細取得** | GET /api/v1/books/{book} | JSON形式で書籍詳細（ジャンル・レビュー含む）が返される。存在しないIDの場合はエラーレスポンスを返す。 |
| **書籍新規登録** | POST /api/v1/books | バリデーション通過時→書籍が登録される。<br>失敗時→エラーレスポンスを返す。 |
| **書籍更新** | PUT /api/v1/books/{book} | バリデーション通過時→書籍が更新される。存在しないIDの場合はエラーレスポンスを返す。 |
| **書籍削除** | DELETE /api/v1/books/{book} | 書籍が削除され、関連データも適切に処理される。存在しないIDの場合はエラーレスポンスを返す。 |
| **★ Sanctum 認証書き込みAPI** | POST/PUT/DELETE /api/v1/books | 書き込み系エンドポイントに Sanctum トークン認証を導入する。認証済み・書籍所有者のみが書き込み可能。未認証時・認可エラー時は適切なHTTPステータスを返す。 |

## 3. 主要機能の画面遷移・関係性（Mermaid）

```mermaid
flowchart TD
    %% 認証系
    Guest((ゲスト)) -->|アクセス| Top[書籍一覧 / 検索 / 詳細 / ランキング]
    Guest -->|登録/ログイン| Reg[会員登録画面]
    Guest -->|ログイン| Login[ログイン画面]
    Reg -->|登録成功| Login
    Login -->|ログイン成功| AuthUser((認証済みユーザー))

    %% 認証ユーザーの動線
    AuthUser --> TopAuth[書籍一覧 / 詳細 / お気に入り]
    TopAuth --> BookCreate[書籍登録画面 / ISBN自動入力]
    TopAuth --> Report[★ マイ読書レポート]
    TopAuth --> Plans[★ 読書計画一覧 / 作成 / 編集]
    TopAuth --> Genres[ジャンル一覧 / 詳細 / 管理]
    TopAuth --> Notif[★ 通知一覧]

    %% レビュー・いいね
    TopAuth -->|書籍詳細| Review[レビュー投稿 / 編集]
    Review -->|いいね| Like[レビューいいね]

    %% API
    Client([外部クライアント]) -->|APIリクエスト| API[公開API /api/v1/books]
    Client -->|Sanctum認証| SecureAPI[書き込み系API]
