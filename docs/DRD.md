# データ要件

| データ名 | 説明 | 管理する情報 | テーブル |
|---------|------|-------------|----------|
| ユーザー | アプリケーション利用者 | 名前、メールアドレス（ユニーク）、パスワード（ハッシュ化）など | `users` |
| 書籍情報 | ユーザーが登録する書籍 | タイトル、著者、ISBN（任意・ユニーク）、出版日（任意）、説明、画像URL、作成者IDなど | `books` |
| ジャンル | 書籍を分類するためのマスタデータ | ジャンル名（ユニーク） | `genres` |
| 書籍×ジャンル | 書籍とジャンルの多対多の関連付け | 書籍ID、ジャンルID | `book_genre` |
| レビュー | 書籍に対するレビュー | 投稿者、対象書籍、評価（1～5）、コメント | `reviews` |
| お気に入り | ユーザーがお気に入り登録した書籍 | ユーザーID、書籍ID | `favorites` |
| レビューいいね | レビューへの「いいね」情報 | ユーザーID、レビューID | `review_likes` |
| 読書計画 | ユーザーごとの読書計画 | ユーザーID、書籍ID、読了予定日、ステータス、読了日時など | `reading_plans` |
| 通知 | 読書計画のリマインダーなどを管理する通知 | 受信者、通知種別、通知内容、既読状態 | Laravel標準の通知テーブル |
| 認証関連 | Laravelが提供する認証・システム管理用データ | パスワードリセットトークン、パーソナルアクセストークン、失敗ジョブなど | Laravel標準テーブル |

## 備考

- ISBNは未登録の書籍にも対応できるよう、`nullable` としています。
- 出版日は不明な書籍にも対応できるよう、`nullable` としています。
- 書籍とジャンルは多対多の関係です。
- 読書計画は、ユーザーごとに書籍の読了予定日や進捗状況を管理します。
- 通知はLaravel標準の通知機能を利用して実装しています。
